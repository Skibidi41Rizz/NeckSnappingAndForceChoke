# Neck Snapping and Force Choke

Grab an enemy by the neck to choke him out, or snap it with one button.

## Features

- **Force choke** - 12 HP/s while you hold the neck, death in about 8 seconds.
- **He fights back** - convulses, loses his footing, kicks his legs and wheezes the whole time.
- **Neck snapping** - press **B** and the neck breaks using the game's own fracture system.
- **No lock-in** - let go and the damage stops instantly.

## Controls

| Input | Action |
|---|---|
| **Grip** | Grab the enemy by the neck |
| **B** / **Y** | Snap the neck while holding it |

Only the neck chokes - grabbing the head or the chest does nothing special.

## Install

1. Install [MelonLoader 0.7.3](https://melonwiki.xyz/) or newer (x64, net6) into BRUTALISTICK VR.
2. Put `NeckSnappingAndForceChoke.dll` into `<game folder>\Mods`.
3. Start the game - the MelonLoader console prints `Neck Snapping and Force Choke: loaded`.

**Uninstall:** delete the DLL from `Mods`.

## Requirements

BRUTALISTICK VR (Steam), MelonLoader 0.7.3+. Single player - not tested with multiplayer mods.

## Troubleshooting

Check `<game folder>\MelonLoader\Latest.log` and search for `Neck Snapping and Force Choke`. If nothing happens, make sure an old `ChokeMelonMod.dll` is not still in `Mods`.
